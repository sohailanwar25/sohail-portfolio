# Muhammad sohail — Resume Website

A responsive, original resume/portfolio website built with HTML, CSS, JavaScript and Bootstrap 5.

## Run locally
Open `index.html` in a browser. An internet connection is needed to load Bootstrap and Google Fonts CDNs.

## Before publishing
1. Replace the example email address in `index.html`.
2. Replace `your-username` with your GitHub username.
3. Verify education details, project descriptions and skills.
4. Add real certifications/achievements only when you have them.

## Publish with GitHub Pages
1. Create a GitHub repository named `resume-website`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` from this folder to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. The URL will normally be `https://YOUR-USERNAME.github.io/resume-website/`.
